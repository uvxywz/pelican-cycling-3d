# 鹈鹕的自由骑行 · 3D

一个可以操控方向的 3D 鹈鹕骑自行车场景。使用原生 WebGL、JavaScript 和 CSS 编写，无第三方运行依赖，无需联网。

## 打开项目

下载项目后，直接在支持 WebGL 的浏览器中打开 `index.html`。不需要安装依赖或执行构建。

也可以在项目目录启动静态服务器，例如安装 Python 后运行：

```sh
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 操作

| 操作 | 效果 |
| --- | --- |
| ↑ / ↓ / ← / → | 输入北 / 南 / 西 / 东方向 |
| 同时按两个相邻方向键 | 输入东北、东南、西北或西南方向 |
| 输入侧向方向 | 朝该方向转一个 45° 档位 |
| 输入正相反方向 | 前轮带动整车，沿顺时针弧线完成调头 |
| R / 调头按钮 | 顺时针调头 |
| 点击八方向轮盘 | 与方向键使用相同转向规则 |
| 空格 / 暂停按钮 | 暂停或继续骑行 |
| 速度滑块 | 调整骑行速度 |
| 在场景中拖动 | 旋转观察视角 |
| 鼠标滚轮 | 缩放 |
| 重置视角 | 恢复初始观察角度 |

例如，目标朝北时，按一次右键转向东北，再按一次右键转向东。每次操作以轮盘选中的目标方向为准；橙色指针显示车身当前朝向。相同方向保持前行，长按不重复转向，松键不额外转向。短时间内的双键输入会合并为一次操作。

地图的北向始终固定，不会随观察视角改变。小地图显示位置和最近行驶轨迹。

## 场景细节

- 地形向四周延伸，起伏带动车身上下运动。
- 前轮、前叉和车把一起转向，后轮沿弧线跟随，双手保持握住车把。
- 前后轮根据各自的行驶路程滚动，双腿位于车架两侧交替踩踏。
- 鹈鹕带有眨眼、腮红、分层羽毛和随风摆动的围巾。
- 围脖采用中空环带，围巾尾端在身体外侧摆动。
- 若系统偏好减少动态效果，首次打开时会暂停，点击播放即可继续。

## 验证

安装 Node.js 18 或更高版本后运行：

```sh
npm test
```

也可以直接运行 `node tests/behavior.test.cjs`。不需要执行 `npm install`。

当前包含 35 组检查，覆盖八方向输入、45° 步进、顺时针调头、双键合并、暂停、调速、视角、车轮与车把连接、围巾几何间隙等。测试使用模拟的 DOM 和 WebGL 接口，验证逻辑与计算；它不替代浏览器中的实际视觉检查。

## 技术说明

车身运动使用以后轮接地点为基准的自行车运动模型。转向角决定车身转弯速率，而非直接旋转整车。场景围绕骑行者使用局部渲染坐标，地形采样与实际行驶位置保持关联。

本项目没有外部资源请求、登录功能或数据收集。浏览器需要支持并启用 WebGL。
